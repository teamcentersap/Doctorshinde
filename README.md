# Dr. Tapre — Specialist Physician

A calm, mobile-friendly website for Dr. Tapre’s specialist consultation practice.

## Preview locally

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Contents

- `index.html` — landing page
- `styles.css` — layout and visual system
- `script.js` — navigation, scroll reveal, booking form note
